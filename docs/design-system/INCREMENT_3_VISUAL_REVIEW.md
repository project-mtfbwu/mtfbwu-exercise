- [ ] Dark grid / checker atmosphere present

- [ ] Pixel stickers / neon accents where appropriate
- [ ] Live HTML controls (inputs, checkboxes, date) — not screenshot chrome
- [ ] Forms readable (contrast) and keyboard operable
