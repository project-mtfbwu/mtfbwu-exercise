## Scanner nested focus

- Dark retro desktop-window chrome
- Live camera gets max practical space on mobile
- Scan frame high-contrast; **no stickers or glitter over the feed**
- Controls large and one-hand reachable; safe areas respected
- Board + meal focus remain visible behind the nested surface

## Label review

- Cream / torn-paper form surface
- Ink-on-paper inputs; neon warnings sparingly for confidence / energy mismatch
- Source + confidence visible; raw OCR expandable
- Save disabled until valid + basis known + explicit confirmation (unchecked)

## Label capture / crop

- Capture tips call out flat / fill / no glare / straight-on
- Explicitly states there is **no** perspective auto-correction
- Crop editor uses high-contrast neon crop frame (not over decorative stickers)
- Rotate / reset / numeric crop controls stay large and reachable
- Retry bar on review: Recrop / Rotate / Use text / Manual

## Viewports to check

- 1440×900, 768×1024, 390×844
- Reduced-motion: no decorative animation over camera; status text still updates
